This is the real thing, not a lookalike. The signal processing is the C code from C-Spectrum compiled to WebAssembly , same FFT, same filters, same envelope analysis that finds a bearing defect frequency.

Knock rate comes from envelope demodulation: it band-passes the high frequencies, rectifies, and transforms what's left, which turns "a resonance being struck repeatedly" back into a plain number. Spikiness is kurtosis , how much the signal is made of sharp peaks rather than a steady hum.
